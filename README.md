# WB Review Intelligence

Плагин для анализа публичных отзывов и вопросов Wildberries в Codex и поддерживаемых средах ChatGPT Work. На вход — ссылка или артикул; на выход — отчёт с проверяемыми цитатами и частотами. Методика, Python-контролёр и оформление находятся внутри пакета.

**Версия1.3.0 — переносимый GitHub-дистрибутив анализатора1.2.2.** Аккаунт OpenAI автора не нужен. Приватный App автора, его Google Drive, токены и реальные исследования в репозиторий не включены. Каждый пользователь подключает свои источники и хранит свои данные.

## Установка в Codex

В среде с установленным Codex CLI:

```bash
codex plugin marketplace add solyarikai/wb-review-intelligence-
codex plugin add wb-review-intelligence@wb-review-intelligence
```

Откройте новый чат после установки, выберите WB Review Intelligence и отправьте ссылку Wildberries. В Desktop источник marketplace должен появиться в каталоге плагинов; установку/включение можно выполнить там. Доступность меню зависит от версии клиента и политик рабочего пространства.

В ChatGPT Work импорт GitHub-marketplace для рабочего пространства выполняется администратором, если эта возможность доступна в его плане/клиенте. Публичный GitHub-репозиторий не означает автоматического появления плагина в общем каталоге OpenAI и не гарантирует установку в любой веб-аккаунт. Руководства: [пакеты и marketplaces](https://developers.openai.com/plugins/build/plugins), [плагины](https://learn.chatgpt.com/docs/plugins).

## Подготовка Python

Для контролёра нужны Python3.10+ и POSIX flock: Linux, macOS или WSL2 на Windows. Прямой запуск в обычном Windows Python не поддержан и не объявляется проверенным.

В используемой для выполнения среде Python установите зависимости:

```bash
python3 -m pip install -r requirements.txt
```

Если pip ограничен системой, используйте отдельное виртуальное окружение. Сбор требует доступных публичных источников/сети. Firecrawl/Tavily используются только если пользователь подключил их в своём аккаунте; собственных ключей автора или отдельного AI API не требуется. При отказе источника плагин честно сообщает ограничение, не обходит защиту и не выдумывает данные.

## Что сохраняется и где

В постоянном проекте Codex:

```text
<ваш проект>/wb-review-intelligence/
  config.json
  registry.jsonl
  index.html
  legacy-index.json        # необязательные ссылки на старые исследования
  runs/<run_id>/
    data/corpus.jsonl      # очищенные отзывы
    data/analysis.json     # разметка, цитаты, Q&A и REPORT_DATA
    data/manifest.json     # происхождение, остаток и статусы
    report.html            # самостоятельный отчёт
    message.html           # производная для поддерживаемого показа в чате
```

В новый чат можно написать: «Покажи сохранённые исследования этого проекта» или «Открой анализ <run_id> без повторного сбора». Просмотр/оформление не запускают WB или новый анализ. Не коммитьте исследовательскую папку в этот репозиторий.

В облачной среде без постоянной папки пользователь отдельно выбирает своё хранилище. Google Drive не нужен для локального режима; установка не даёт доступ к чьим-либо файлам.

## Как устроен пакет

```text
.agents/plugins/marketplace.json
plugins/wb-review-intelligence/
  plugin.json
  .codex-plugin/plugin.json
  skills/analyze-wb-reviews/
    SKILL.md
    references/
    scripts/
    schemas/
    assets/report/
    tests/
  skills/setup/SKILL.md
```

Например, `references/LOCAL-PROJECT.md` в SKILL.md — файл внутри того же каталога навыка, а не документ на Drive. Установленная копия пакета находится в кэше клиента; данные исследований — в отдельном выбранном проекте. Кэш не редактируют для обновления.

## Обновление

```bash
codex plugin marketplace upgrade wb-review-intelligence
```

Затем проверьте версию установленного плагина в клиенте и откройте новый чат. Публикация коммита не доказывает загрузку обновления на другом устройстве. Старые исследования хранятся в проекте и не включаются в пакет обновления. Обновления приложения OpenAI, GitHub-пакета и пользовательских данных — разные действия.

## Проверки и ограничения

```bash
python3 -m unittest discover -s plugins/wb-review-intelligence/skills/analyze-wb-reviews/tests -p 'test_*.py' -v
```

Fixtures синтетические. Полнота источника, обработка всех текстов, проверка цитат и реальный UI имеют отдельные статусы. Один отзыв может содержать несколько тем; частоты не являются процентом брака или возвратов. Работа на конкретном другом аккаунте и фактическая установка должны проверяться в его клиенте.
