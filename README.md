# WB Review Intelligence

**Версия: 1.3.0**

Плагин для исследования отзывов и вопросов покупателей на Wildberries. Вы отправляете ссылку на товар или артикул и получаете отчёт: что покупатели хвалят, на что жалуются, какие вопросы задают и что можно улучшить в предложении.

Каждый вывод связан с отзывами, а частоты тем рассчитаны по уникальным текстовым отзывам выбранной области.

## Возможности

- Анализ доступных публичных отзывов и вопросов с ответами продавца.
- Отдельные результаты по исходному артикулу и объединённой группе товаров.
- Темы с частотами, точными цитатами и полным контекстом исходного поля.
- Выводы и предложения по улучшению товара, описания и комплектации.
- Интерактивный отчёт с поиском, фильтрами и раскрытием подтверждений.
- Сохранение исследований в проекте и продолжение работы в новом чате.

## Установка

В Codex CLI выполните:

```bash
codex plugin marketplace add solyarikai/wb-review-intelligence-
codex plugin add wb-review-intelligence@wb-review-intelligence
```

После установки откройте новый чат и выберите **WB Review Intelligence**.

В Codex Desktop плагин доступен через подключённый источник в каталоге плагинов. Для ChatGPT Work импорт GitHub-каталога выполняется через настройки рабочего пространства, если это поддерживается его планом и политиками. Подробнее: [установка плагинов и каталогов](https://developers.openai.com/plugins/build/plugins).

### Среда выполнения

Для обработки данных нужен Python 3.10 или новее. Поддерживаемые среды: Linux, macOS и WSL2 на Windows.

В используемом виртуальном окружении Python установите зависимости:

```bash
python -m pip install "jsonschema>=4.18,<5" "referencing>=0.28.4,<1"
```

Для получения отзывов нужен доступ к публичным источникам. Плагин использует доступные средства чтения веб-данных, включая Firecrawl или Tavily при их подключении. Для проверки среды после установки можно попросить: «Проверь настройку WB Review Intelligence».

## Использование

Откройте папку проекта в Codex, выберите плагин и отправьте ссылку на карточку Wildberries или артикул.

Примеры запросов:

> Проанализируй отзывы по этой карточке: <ссылка Wildberries>.

> Покажи сохранённые исследования этого проекта.

> Открой исследование <run_id> без повторного сбора отзывов.

> Покажи все жалобы на комплектацию в сохранённом исследовании <run_id>.

Готовый отчёт содержит четыре раздела: **Обзор**, **Темы**, **Вопросы**, **Возможности**. Темы можно фильтровать по тональности, искать по названию или тексту цитат и раскрывать до исходных подтверждений.

При поддержке клиентом отчёт отображается прямо в чате. Также сохраняется самостоятельный HTML-отчёт. В клиентах без встроенного HTML результат выводится текстом.

## Как проходит исследование

1. Плагин проверяет карточку товара, артикул и состав объединённой группы.
2. Получает доступные отзывы и вопросы, удаляет дубли записей и сохраняет исходные данные.
3. Агент последовательно читает все полученные текстовые отзывы и выделяет темы.
4. Программы проверки сверяют цитаты с исходными полями, принадлежность отзывов и частоты тем.
5. Плагин формирует отчёт и добавляет исследование в историю проекта.

Отзывы артикула и всей группы учитываются отдельно. Вопросы и ответы продавца показываются отдельным разделом и не увеличивают частоты тем из отзывов.

Каждое новое исследование получает идентификатор `run_id`. Просмотр отчёта, уточняющие вопросы и изменение оформления используют сохранённые данные этого запуска.

## Где хранятся исследования

В постоянном проекте Codex плагин создаёт папку `wb-review-intelligence`:

```text
<проект>/wb-review-intelligence/
├── config.json
├── registry.jsonl
├── index.html
├── legacy-index.json          # при наличии исследований прежних форматов
└── runs/
    └── <run_id>/
        ├── data/
        │   ├── corpus.jsonl
        │   ├── analysis.json
        │   └── manifest.json
        ├── report.html
        └── message.html
```

| Файл | Назначение |
| --- | --- |
| `config.json` | Настройки локального хранения проекта. |
| `registry.jsonl` | Реестр запусков, путей, контрольных сумм и статусов. |
| `index.html` | Общая история исследований со ссылками на отчёты. |
| `legacy-index.json` | Ссылки на ранее сохранённые исследования других форматов; файл необязателен. |
| `corpus.jsonl` | Очищенные исходные отзывы. |
| `analysis.json` | Разметка, темы, цитаты, вопросы, ответы и данные отчёта. |
| `manifest.json` | Происхождение данных, охват, ход обработки и результаты проверок. |
| `report.html` | Самостоятельный отчёт для открытия в браузере. |
| `message.html` | Версия отчёта для встроенного показа в чате. |

Один запуск хранится в одной папке. Его HTML-файлы строятся из тех же данных. Чтобы продолжить работу в другом чате, откройте тот же проект и укажите `run_id` или попросите показать историю.

В облачной среде без постоянной папки проекта место долговременного хранения выбирается при первоначальной настройке.

## Как устроен плагин

Файлы плагина устанавливаются в кэш клиента и содержат инструкции, программы и оформление отчёта:

```text
.agents/plugins/marketplace.json
plugins/wb-review-intelligence/
├── plugin.json
├── .codex-plugin/plugin.json
└── skills/
    ├── analyze-wb-reviews/
    │   ├── SKILL.md
    │   ├── references/
    │   ├── scripts/
    │   ├── schemas/
    │   ├── assets/report/
    │   └── tests/
    └── setup/SKILL.md
```

| Каталог или файл | Назначение |
| --- | --- |
| `marketplace.json` | Описание каталога для установки плагина. |
| `plugin.json` | Название, версия и параметры плагина. |
| `SKILL.md` | Основная инструкция выполнения исследования. |
| `references/` | Методика получения, анализа, проверки и сохранения данных. |
| `scripts/` | Python-программы управления обработкой, проверок, хранения и сборки отчёта. |
| `schemas/` | Описание допустимых структур данных. |
| `assets/report/` | Шаблон, стили и код интерактивного отчёта. |
| `tests/` | Синтетические проверки программ. |
| `setup/SKILL.md` | Инструкция проверки первоначальной настройки. |

Путь `references/LOCAL-PROJECT.md` в инструкции навыка указывает на файл внутри его каталога. Данные исследований находятся в папке проекта, отдельно от установленного пакета.

## Обновление

```bash
codex plugin marketplace upgrade wb-review-intelligence
```

Проверьте установленную версию в клиенте и откройте новый чат. Сохранённые исследования остаются в папке проекта и доступны после обновления.

## Как читать результаты

- Объём доступных данных зависит от источника. В отчёте указываются фактически полученные записи и ограничения охвата.
- Частоты рассчитаны среди текстовых отзывов выбранной области. Один отзыв может затрагивать несколько тем, поэтому проценты тем не обязаны складываться в 100%.
- Частота жалобы не равна доле брака или возвратов.
- Ответы продавца представлены как его заявления.
- Полнота источника, завершённость обработки, проверка доказательств и работа интерфейса оцениваются отдельно.
