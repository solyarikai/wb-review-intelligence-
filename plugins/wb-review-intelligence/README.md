# WB Review Intelligence

**Версия: 1.3.0**

Плагин для анализа отзывов и вопросов покупателей на Wildberries. Формирует отчёт с темами, частотами, точными цитатами и предложениями по улучшению товара и его представления.

## Быстрый старт

1. Установите плагин по [инструкции в корне репозитория](../../README.md#установка).
2. Откройте проект в Codex и выберите **WB Review Intelligence** в новом чате.
3. Отправьте ссылку на карточку Wildberries или артикул.

Для проверки среды попросите: «Проверь настройку WB Review Intelligence».

## Результат исследования

Отчёт включает четыре раздела: **Обзор**, **Темы**, **Вопросы**, **Возможности**. В нём доступны поиск по темам и цитатам, фильтры по тональности и раскрытие подтверждений.

Для исходного артикула и объединённой группы используются отдельные частоты. Вопросы и ответы продавца показываются отдельно от отзывов. Охват источника и результаты проверок указаны в отчёте.

## Сохранение и продолжение

В постоянном проекте Codex исследования находятся в `<проект>/wb-review-intelligence/`:

```text
registry.jsonl                  # реестр исследований
index.html                      # общая история
runs/<run_id>/
  data/corpus.jsonl             # исходные отзывы
  data/analysis.json            # разметка, цитаты и данные отчёта
  data/manifest.json            # охват, обработка и проверки
  report.html                   # самостоятельный отчёт
  message.html                  # отчёт для показа в чате
```

Чтобы вернуться к результату, откройте тот же проект и попросите: «Открой исследование <run_id> без повторного сбора отзывов».

## Состав пакета

- `skills/analyze-wb-reviews/SKILL.md` — порядок исследования.
- `references/` — методика и правила отдельных этапов.
- `scripts/` — программы обработки, проверки, хранения и сборки отчёта.
- `schemas/` — структуры данных.
- `assets/report/` — оформление и интерактивные элементы отчёта.
- `tests/` — синтетические проверки.
- `skills/setup/SKILL.md` — первоначальная проверка среды.

Каталоги `references`, `scripts`, `schemas`, `assets` и `tests` находятся внутри `skills/analyze-wb-reviews`. Относительные пути из SKILL.md разрешаются от этого каталога.

Требования к Python, команды установки и обновления, полная структура хранения и описание расчётов приведены в [документации проекта](../../README.md).
