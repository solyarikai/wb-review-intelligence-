# WB Review Intelligence ·1.3.0

Переносимый skills-плагин на основе анализатора1.2.2: сбор доступных публичных отзывов и Q&A Wildberries, смысловой анализ всех полученных текстов, точные цитаты, отдельные области article/group, проверяемые частоты и закреплённый интерактивный отчёт.

Установка и обновления описаны в README корня GitHub-репозитория. Пакет не содержит приватного App, аккаунта Drive, токенов, данных исследований и абсолютных путей автора. На каждом аккаунте доступны только его собственные инструменты и файлы.

## Начало

Выберите @WB Review Intelligence и пришлите ссылку/артикул. Для проверки среды доступен setup. Python3.10+, jsonschema/referencing, POSIX flock необходимы для контролёра. Источники могут быть недоступны; плагин не обходит защиту и не гарантирует полную выгрузку.

## Файлы пакета

skills/analyze-wb-reviews/SKILL.md — маршрут. references/ — методика, scripts/ — контролёр/хранение/проверки, schemas/ — структуры данных, assets/report/ — локальный renderer, tests/ — только синтетика. Относительные пути считаются от каталога навыка, не от папки пользовательского исследования.

## Файлы исследований

В постоянном проекте Codex все новые данные только в wb-review-intelligence/runs/<run_id>/data/{corpus.jsonl,analysis.json,manifest.json}. report.html/message.html рядом — производные того же запуска; registry.jsonl/index.html — общая история. Не создавать второй комплект другим навыком. Пакетный кэш и GitHub-репозиторий не используются для хранения отзывов.

Продолжение — прежний run_id и файлы, без WB и нового анализа ради просмотра/оформления. Прежние исследования могут включаться ссылками через legacy-index.json, без копирования. В облачной среде без постоянного проекта хранилище настраивает сам пользователь по04-STORAGE.md; установки недостаточно для доступа к Drive.

Источник, обработка, доказательства и UI независимы. Встроенный отчёт показывать по фактической поддержке клиента; Python/DOM-тесты не являются подтверждением кликов пользователя. При отсутствии встроенного HTML — содержательный Markdown, а HTML-файл дополнительно.
