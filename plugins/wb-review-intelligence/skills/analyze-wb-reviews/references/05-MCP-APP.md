# Дополнительные серверные приложения

Переносимый GitHub-пакет1.3.0 является skills-плагином: включает методику, Python-контролёр, валидаторы и закреплённый локальный renderer. Приватный MCP App автора, его endpoint и подключение не входят в пакет и для обычного анализа не нужны.

Не пытайся вызывать open_wb_report/import_wb_report/list_wb_reports, если таких разрешённых инструментов фактически нет. Не направляй чужие исследования в сервис владельца. Не создавай сервер/App ради оформления.

Основной путь: сохранённые три файла → pipeline report → local_project checkpoint --render → content-reference доступного клиенту встроенного механизма. При недоступности HTML — содержательный Markdown и самостоятельный report.html. Локальная история проекта — local_project list/index.html, а не список стороннего App.

Если пользователь отдельно поручает подключить собственный MCP-сервис или опубликовать отчёт, рассмотри это как самостоятельное действие с его доступами и хранилищем. Установка GitHub-пакета сама такого разрешения не даёт. Успешный render, App-вызов и настоящие клиентские клики — разные проверяемые факты.
